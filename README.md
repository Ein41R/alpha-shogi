# alpha-shogi
Train an AI model to learn Shogi via Self-Supervised and reinforcement learning.

### Description
This is set to be the framework to train a shogi Ai on data in the  YaneuraOu PackedSfenValue format.
This model is set to be a bdh based model and it is my introduction project to reinforcement learning. 
The reason we still use self-supervised learning is;
1. To create a foundation model that can be fine tuned with RLHF.
2. To revise what I have learned in a prior project and deepen my knowledge about training methods.

### GOALS:
1. learn reinforcement learning
2. Get better at shogi
3. (optional) leverage different optimizers, learning rates and other parameters tuned in the process of rl
